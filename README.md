# Crystal Gardens Website

Premium static website for Crystal Gardens Landscape & Gardening Services in Nairobi.

## Files

- `index.html` - Homepage content, SEO metadata, structured data, and conversion form
- `styles.css` - Responsive visual system and layout
- `script.js` - Mobile navigation, service-to-quote flow, and WhatsApp quote message

## Preview locally

Open `index.html` directly in a browser, or serve the folder:

```powershell
python -m http.server 4173
```

Then visit `http://localhost:4173`.
